# 🐍 Python Learning & Skill Planner

A Python CLI application designed to calculate available study hours and track acquired technical skills up until university enrollment in **January 2028**.

---

## 📌 Features

* **Study Hours Calculation:** Computes total accumulated study hours over a 68-week roadmap.
* **Skill Tracker:** Interactive CLI loop allowing users to register new technical skills.
* **Data Persistence:** Utilizes JSON file handling (`habilidades.json`) so your skills history is never lost.
* **Error Handling:** Implements `try/except` blocks to handle missing data files gracefully.
* **Clean Code:** Structured into modular functions (`def`) following clean code practices.

---

## 🛠️ Built With

* **Language:** Python 3.x
* **Data Format:** JSON
* **Version Control:** Git & GitHub
